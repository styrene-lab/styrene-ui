# Desktop operator workspaces

## Intent

Replace subsystem tabs with stable destinations that communicate current state.
Overview summarizes actionable conditions; Browse owns NomadNet browsing;
Messages includes Delivery. Network remains connection administration.

## Scope

Desktop shell, summary rail, actionable Overview, nested Delivery, and Browse
naming/continuity. Preserve existing backend contracts and Identity ownership.
New bookmarks, I2P/browser launch adapters, Yggdrasil service discovery, and
profile CRUD are subsequent work; do not offer unimplemented controls.

## Success criteria

Seven stable destinations, truthful summaries, usable narrow-window navigation,
retained browsing state, reachable delivery diagnostics, and no runtime fallback.
