# Design

## Roster row

Grid columns: glyph, identity, facts, chevron. Identity holds the name on one
line with ellipsis and, beneath it, the short hash beside an aspect tag
(LXMF, Propagation, NomadNet). Facts is a right-aligned technical column
with the age ("11m ago") over the announce count ("×113", labelled for
assistive technology as "113 announces"). Columns are explicit sizes so no
free space lands between fields.

## Network bearer board

Each bearer row keeps its name, reason, and tone chip. Beneath the TCP row the
endpoint editor renders as the row's configuration: an "active" chip beside
the configured endpoint while the bearer is connected, then the input and
Apply on one line. Beneath the Bluetooth RNode row the adapter controls render
without their own heading. The separate endpoint card and Bluetooth card are
gone, and the Android USB bearer is not shown on iOS.
